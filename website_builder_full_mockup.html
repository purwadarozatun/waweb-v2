Assets

Pilih aset dari sidebar

spec.jsondefinisi aset template
{ "template": "landing-page-v1", "assets": [ { "key": "hero_image", "type": "image", "value": "hero.jpg" }, { "key": "logo", "type": "image", "value": "logo.png" }, { "key": "hero_title", "type": "text", "value": "Judul halaman" }, { "key": "hero_desc", "type": "text", "value": "Deskripsi singkat" }, { "key": "cta_label", "type": "text", "value": "Daftar Sekarang" } ] }
index.htmlreferensi aset via path
<img src="assets/hero_image/hero.jpg"> <img src="assets/logo/logo.png"> <h1 data-key="hero_title"></h1> <p data-key="hero_desc"></p> <a data-key="cta_label"></a>
app.jsload value.json saat runtime
fetch('assets/value.json') .then(r => r.json()) .then(data => { document.querySelectorAll('[data-key]') .forEach(el => { el.textContent = data[el.dataset.key] }) })
